# Screenshots

Captured from the port itself on Linux (RTX 3070 Ti), from the developer's own copy of the game, newest first.
The 2026-11-23 set is the frame the port presents to its window (`PS3RECOMP_VK_DUMP_PRESENT`) at 1920x1080, and at
3440x1440 borderless for the 21:9 shot (scaled to 2580x1080 here); the 2026-10-30 set is a headless run at the
game's 1280x720 (`PS3RECOMP_VK_DUMP_MS`). Levels were reached with `KZ_UNLOCK_LEVELS=1` and played with
`KZ_DEBUG_GOD=1` on scripted input. Nothing here is from the PS3.
