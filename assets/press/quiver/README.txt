Quiver Launcher badge

badge.png (313x56) and badge@3x.png (939x168) are drawn by tools/release/press_badges.py, text only:
"GET IT ON / Quiver Launcher", in the size of the RecompLauncher badge so the two line up.

Quiver Launcher has no press kit. Its TRADEMARKS.md allows a project to say truthfully that it works with Quiver
Launcher, but not to use the Quiver logo or app icons, or artwork that could be mistaken for them. This badge uses
none of them: only the name, in this project's own font and neutral colours. It links to the port's page:
https://quiverlauncher.com/apps/killzone-hd-project-vekta

"Quiver" and "Quiver Launcher" are their owner's marks.
